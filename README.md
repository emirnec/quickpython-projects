# Quick Python Projects

Three small Python practice scripts:

| File | Description |
|---|---|
| `Odd or Even number calculator.py` | Reads a number and reports whether it is even |
| `font changer.py` | Small Tkinter utility for changing displayed font settings |
| `rolling a die.py` | Simulates rolling a die |

## Run

```bash
python "Odd or Even number calculator.py"
python "rolling a die.py"
python "font changer.py"
```

These are beginner exercises and require only the Python standard library (Tkinter is included with standard Python installers on Windows).
